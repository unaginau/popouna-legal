Draft TikTok videos for the Popouna creator account

Official content workflow for Popouna (@popouna_unagi): prepare videos, upload drafts to TikTok inbox via Content Posting API, then publish in the TikTok app.

Terms of Service Privacy Policy X / @popouna_unagi Charaforio

How it works

  1. Operator prepares a Popouna video and caption.
  2. Login Kit connects the official Popouna TikTok account.
  3. Content Posting API (video.upload) sends the video as an inbox draft.
  4. The operator opens the TikTok notification, reviews, and publishes manually.

TikTok products used

  • Login Kit — user.info.basic for account authorization
  • Content Posting API — video.upload inbox/draft upload only (no Direct Post)
Operator: Popouna / @popouna_unagi
