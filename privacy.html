Privacy Policy

Last updated: 2026-11-20

Popouna SNS Helper is an official content-operations tool for the Popouna character IP. It uploads draft videos to the Popouna TikTok account via TikTok’s Content Posting API.

Data we access

  • TikTok account identity needed to authorize uploads (user.info.basic)
  • Media files the operator chooses to upload

How we use data

Data is used only to authorize the Popouna account and to upload draft content to TikTok inbox. We do not sell personal data. We do not use data for advertising.

Storage

Access tokens are stored securely in the operator’s private configuration. Media is processed only for the upload the operator initiates.
