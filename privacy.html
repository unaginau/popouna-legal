Privacy Policy

Last updated: 2026-11-19

This app (“Popouna SNS Helper”) is a private tool operated by the Popouna character IP for uploading draft videos to the operator’s own TikTok account via TikTok’s Content Posting API.

Data we access

  • TikTok account identity needed to authorize uploads
  • Media files the operator chooses to upload

How we use data

Data is used only to upload draft content to the operator’s TikTok inbox and to manage that authorization. We do not sell personal data. We do not use data for advertising.

Storage

Access tokens are stored securely on the operator’s private machine or private configuration. Media is processed only for the upload the operator initiates.
